# Roadmap

From rented clouds to an open network. The core works on mainnet. Next, runs move onto our own
servers, and last onto machines anyone can offer.

1. **Today:** Sandbox time bought from cloud providers and sold per run.
2. **Our own servers:** Runs move from rented clouds onto machines we operate.
3. **GPU sandboxes:** Machines with GPUs for AI models.
4. **More clients:** Live tests in Cursor, Codex and VS Code.
5. **An open network:** Anyone can be a sandbox provider on their own machine and get paid per run.
   It is the hardest step, because untrusted code has to stay isolated on machines we don't
   control.
